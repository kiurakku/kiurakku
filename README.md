### 🌱 Про мене

> 🦠 **Malware Analyst** — головний фокус: **статичний і динамічний аналіз** шкідливого ПЗ, **reverse engineering** бінарників, розбір **вірусів / троянів / лоадерів**, витяг **IOC**, YARA-правила та відтворювані **malware labs**.
