# Security

## Reporting a vulnerability

Please report security issues **privately** (do not open a public issue for undisclosed vulnerabilities):

- **Email:** [yanginero@outlook.com](mailto:yanginero@outlook.com)

Include enough detail to reproduce or assess impact. For problems in a **specific repository**, mention the repo name and, if possible, a minimal proof of concept.

## Scope

This policy applies to repositories under the [kiurakku](https://github.com/kiurakku) GitHub account. For third-party dependencies, use the upstream project’s disclosure process.
